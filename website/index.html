  • “Summarize this page.”
  • “Explain this paragraph.”

A quick question stays quick. A bigger one becomes a Mission.

Missions

Give Py a goal.

A Mission is a persistent workspace for one goal — it keeps its own goal, constraints, findings, sources, and result together, and you can leave and come back to it.

Goal

Find the best hard-court tennis shoes under $120.

Constraints

  • under $120
  • hard-court durability
  • lateral support

Findings

  • ASICS Gel-Resolution 9 — $115, strong lateral support
  • Wilson Rush Pro 4.0 — $110, reinforced for hard courts

Sources

3 reviewed · 2 useful · 1 skipped

Result

The Wilson Rush Pro 4.0 is the best fit — $110, reinforced for hard courts, with strong lateral support.

Missions keep their goal, constraints, progress, findings, sources, and result together — so picking a task back up doesn't mean starting over.

Meet Py

The assistant inside PyBrowser.

Py is not the logo, and not decoration — Py's pose and expression are tied directly to what the browser is actually doing.

Idle

Ready when you are.

Select a state to see its motion. Motion is subtle by design — a breath, a lean, a small transition between states — and it stops entirely when your system asks for reduced motion.

Technology

Built with Python. Designed for AI-native browsing.

PyBrowser is a desktop browser built primarily in Python, with a Qt-based interface and Chromium-powered web rendering. Its AI systems are integrated directly into the browser, rather than living in a separate chat window — Py understands pages, navigates the web, manages Missions, and returns structured results from inside the browsing session itself.

Python

Core application logic, end to end.

Qt (PySide6)

The native desktop interface.

Qt WebEngine

Chromium-based web rendering — real pages, not a mock.

Multiple AI providers

Anthropic (Claude), Google Gemini, Groq, and OpenRouter.

Mission system

Persistent, structured multi-step tasks with their own store.

Safety layer

Action sensitivity is classified by the browser, not the model.

Engineering

Built from the ground up.

  • Missions persist their goal, constraints, findings, sources, and result across restarts.
  • Browser actions go through one structured, auditable API — not raw scripting.
  • History, bookmarks, and downloads are backed by a real local database.
  • Light and dark themes follow the desktop's own preference.
  • Covered by an automated test suite exercised on every change.

About

About PyBrowser

PyBrowser is an experimental AI-native desktop browser focused on making the web more actionable. Instead of only displaying pages, PyBrowser is designed to help you research, compare, organize, and complete work directly across the web.

PyBrowser is an independent software project, built in Python and currently in active development.
