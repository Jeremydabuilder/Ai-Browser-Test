Missions

Give Py a goal.

A Mission is a persistent workspace for one goal — it keeps its own goal, constraints, findings, sources, open questions, result, and activity together, and you can leave and come back to it.

Goal

Find the best hard-court tennis shoes under $120.

Constraints

  • under $120
  • hard-court durability
  • lateral support

Findings

  • ASICS Gel-Resolution 9 — $115, strong lateral support
  • Wilson Rush Pro 4.0 — $110, reinforced for hard courts

Sources

3 reviewed · 2 useful · 1 skipped

Result

The Wilson Rush Pro 4.0 is the best fit — $110, reinforced for hard courts, with strong lateral support.

Missions keep their goal, constraints, progress, findings, sources, and result together — so picking a task back up doesn't mean starting over.

Context

Py keeps the thread.

Inside a Mission, Py doesn't forget what it was doing. A Mission holds its own:

  • Goal
  • Constraints
  • Findings
  • Sources
  • Progress
  • Result

This is per-Mission memory, not a general personal memory that follows you across every unrelated task — close a Mission and reopen it days later, and it still knows where it left off.

Safety & control

You stay in control.

PyBrowser asks before important actions — the kind that reach outside your own Mission board and actually change something. Py keeps working on everything else without interrupting you for it.

  • Submitting forms
  • Sending messages
  • Purchases
  • Deleting data
  • Sharing sensitive information

I'll ask before anything important.

Privacy

Your data, your control.

Nothing is sent anywhere unless you ask Py to do something. Browsing normally — tabs, history, bookmarks — stays on your machine the whole time.

  • Browsing history, bookmarks, downloads, and Missions are stored locally, in a database file on your own machine.
  • API keys are stored in your operating system's own secure keyring — never written to a plain settings file.
  • When you ask Py something, the page content and your request are sent to whichever AI provider you've configured (Anthropic, Google, Groq, or OpenRouter) — subject to that provider's own data-handling terms.
  • PyBrowser itself has no analytics, telemetry, or tracking built in, and no server of its own that your browsing is sent to.
  • Connected tools (see "Connect Py to your tools" above) are not available yet — once they are, a connected tool only sees what a Mission actually sends it, and every write still goes through the same approval step described above.

Technology

Built with Python. Designed for AI-native browsing.

PyBrowser is a desktop browser built primarily in Python, with a Qt-based interface and Chromium-powered web rendering. Its AI systems are integrated directly into the browser, rather than living in a separate chat window — Py understands pages, navigates the web, manages Missions, and returns structured results from inside the browsing session itself.

Python

Core application logic, end to end.

Qt (PySide6)

The native desktop interface.

Qt WebEngine

Chromium-based web rendering — real pages, not a mock.

Multiple AI providers

Anthropic (Claude), Google Gemini, Groq, and OpenRouter.

Mission system

Persistent, structured multi-step tasks with their own store.

Safety layer

Action sensitivity is classified by the browser, not the model.

Engineering

Built from the ground up.

  • Missions persist their goal, constraints, findings, sources, and result across restarts.
  • Browser actions go through one structured, auditable API — not raw scripting.
  • History, bookmarks, and downloads are backed by a real local database.
  • Light and dark themes follow the desktop's own preference.
  • Covered by an automated test suite exercised on every change.

About

About PyBrowser

PyBrowser is an experimental AI-native desktop browser focused on making the web more actionable. Instead of only displaying pages, PyBrowser is designed to help you research, compare, organize, and complete work directly across the web.

PyBrowser is an independent software project, built in Python and currently in active development.
